# 📚 BookNest - Library Management System

BookNest is a full-stack **Library Management System** designed to modernize and simplify library operations with real-time database connectivity, an interactive dashboard, and a fully responsive UI.

---

## 🚀 Features

* 🔐 **Admin Login & Logout**
* 🧑‍💼 **Dynamic Admin Profile**
* 🏠 **Modern Card-View Dashboard**
* 📚 **Book Management** (Add / Update / Delete / View)
* 📦 **Allot Book & Cart System**
* 🔄 **Return System**
* 🕒 **Submission & Allotment History**
* 👥 **Student Management** (Add / Update / Delete)
* 💸 **Purchase Book Information** (CRUD)
* 🏢 **Vendor Management** (CRUD)
* 📰 **Publication Management** (CRUD)
* 📨 **Subscription Management** with **Auto Fee Update**
* 📱 **Fully Responsive Web UI**
* 💾 **All Operations Database Driven**

## ⚙ Setup & Installation

### Prerequisites

* Java 17 or above
* MySQL
* Maven
* IDE: IntelliJ IDEA / STS / Eclipse

### Installation Steps

```bash
# Clone the repository
git clone https://github.com/your-username/BookNest.git

# Import in IDE and configure application.properties
spring.datasource.username=your_user
spring.datasource.password=your_password

# Run the project
mvn spring-boot:run
```
